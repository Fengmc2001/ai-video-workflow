# 局部精修：一次改一件事

精修前，先把要变的部分说具体。

本片在0—4秒的行走远景中加入林浩的一句感叹，让“自行车累”自然接到“想骑电动车”。画面沿用已有镜头，新的同期声参考林浩原有对白的音色，后面的台词继续保留。

这种改法也适合补一个称呼、调整一句话的语气，或者替换一小段旁白。需要准备的内容是：

| 项目 | 示例 |
| --- | --- |
| 区间 | 0—4秒 |
| 角色 | 林浩 |
| 新台词 | 自行车天天骑着也太累了！ |
| 声音依据 | 同一角色紧邻镜头中的清晰对白 |
| 接续 | 新句结束后留一点环境声，再接原对白 |

如果新声音来自一段生成视频，可以直接提取其音轨：

```bash
aivideo patch-audio original.mp4 new-line.mp4   --start 0 --end 4 --crossfade-ms 60   --output refined.mp4
```

命令会复制原视频画面，只替换指定时间内的声音，另存一份 WAV 母版。`crossfade-ms` 作用于区间末尾，适合放在台词结束后的环境声位置。先听完整的新句和下一句，再决定区间。
