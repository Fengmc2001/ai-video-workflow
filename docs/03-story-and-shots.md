# 把观点写成一段对话

我把本片分成两段。G1 展开争论，G2 让三个人把话说完。前后各约26秒，衔接后是52.13秒。

开头先让林浩说：“自行车天天骑着也太累了！”这句随口的感叹给了他换车的理由。随后，他说自己技术好，许诺回应规则；林浩又提出“就去附近”的想法。张伟接上“我爸妈同意”，把另一个常见理由带进讨论。最后，两位男生分别接受建议。

| 段落 | 台词承担的作用 | 画面安排 |
| --- | --- | --- |
| 开场 | 交代林浩的动机 | 林荫道远景，三人一起走 |
| 林浩表达想法 | 让自信与侥幸自然流露 | 中近景，扶着自行车 |
| 许诺提醒 | 第一次回应规则与危险 | 近景，认真看朋友 |
| 林浩、张伟继续询问 | 展开“路近”和“家长允许”的理由 | 人物反应与三人同框 |
| 许诺解释 | 同时回应两个人 | 从张伟看向林浩 |
| 两人接受 | 各自说出自己的选择 | 分别给近景，再回到远景 |

安排镜头时，让每个镜头有一个主要动作。说话的人说完整一句，另外两个人听、看、点头。这样表演有余地，对话也更容易落在正确的角色身上。

场景则要留下固定的空间关系：校门方向、夕阳位置、围栏、长椅和自行车归属。下一段开场使用上一段末帧作参考，人物站位接着往下演。
