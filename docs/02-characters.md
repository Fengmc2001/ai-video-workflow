# 人物先有想法，再有长相

三个人争论同一件事，各自得有站得住脚的理由。写人物时，我先想他会怎么说话、怎么回应别人，再选择能被镜头记住的外形。

| 角色 | 想法与性格 | 外形锚点 | 声音与动作 |
| --- | --- | --- | --- |
| 林浩 | 自信，爱逞强，愿意听道理 | 偏瘦、黑色碎发、黑红书包 | 清亮的少年音；扶车、轻扬下巴，接受建议时点头 |
| 许诺 | 认真，也在乎朋友的感受 | 高马尾、藏青书包 | 吐字清楚；目光在两位同学之间自然移动 |
| 张伟 | 活泼憨厚，习惯先征求认同 | 微胖、圆脸、寸头、橙色书包 | 比林浩稍厚的少年音；挠头、看看两人，再开朗地回应 |

“微胖、寸头、橙色书包”能让张伟从同框中很快被认出来。林浩的辨识度则来自体态、发型，以及始终由他扶着的深蓝色自行车。

参考图最好同时给出全身、半身和近脸，穿搭统一。确认形象后，把角色 ID 写进台词和分镜；例如 `linhao` 一直对应林浩，不能只靠“左边那个男生”来指代。
