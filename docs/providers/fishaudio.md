# Fish Audio：按角色制作独立配音

需要单独掌握语速、停顿和角色音色时，可以把台词按角色拆开，在Fish Audio中生成。

先为每个人选定声音，再连续试听同一个角色的几句话。初中生的自信、犹豫和轻松，适合通过语气和停顿体现。许诺是在劝朋友，说话可以认真，也留一点柔和。

把选择记成角色与声音的对应关系，密钥放在环境变量中。生成后，将每句WAV标上角色与台词编号，按实际时长放入镜头。

| 文件名 | 内容 |
| --- | --- |
| linhao-A1.wav | 林浩表达想法 |
| xunuo-B1.wav | 许诺第一次提醒 |
| zhangwei-C1.wav | 张伟提出自己的理由 |

声音可以有自然的语气词。字幕跟着最终听到的内容校对，镜头则给完整的尾音和反应留出时间。局部替换使用 `aivideo patch-audio`，分段合成时也可以在timeline中指定音频。

本仓库的交通安全成片使用Dreamina同期声。这个流程供其他题材选择独立配音时使用。

入口与API文档：[Fish Audio](https://fish.audio/) · [官方文档](https://docs.fish.audio/)。
