# Flow：沿用人物与分镜

换到Flow时，继续使用项目里的角色图、场景图、分镜和台词表。先按每个镜头需要的构图准备图片，再把动作与镜头运动写进视频提示词。

操作顺序：

1. 新建项目，按角色和场景整理参考图。
2. 打开本片分镜，确定这一段的开场构图、主要动作和结尾画面。
3. 上传当前入口支持的参考素材，填入对应提示词。
4. 完成一段后，检查人物与对白，再用末帧衔接下一段。
5. 下载视频，交给本地后期工具。

音频可以选视频原生声音，也可以按[Fish Audio流程](fishaudio.md)单独制作。采用独立配音时，镜头长度按实际发声安排。

入口：[Google Flow](https://flow.google.com/)。参考图数量、单段时长和可用模式以当前界面为准。
