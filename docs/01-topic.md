# 先把要讲的事写清楚

一分钟的短片，先抓住一个具体的分歧。谁想做什么？另一个人为什么不同意？聊完以后，他们会作出什么选择？

《骑电动车的小争论》从放学路上的一句抱怨开始。林浩觉得天天骑自行车太累，想换电动车；许诺提醒他注意上路年龄，张伟则觉得父母同意就可以。三个人都在谈自己熟悉的生活，规则随着争论进入故事。

开工前先填这几项：

| 项目 | 本片的答案 |
| --- | --- |
| 观众 | 初中生 |
| 场合 | 道法课堂中的情境短片 |
| 分歧 | 骑得熟、路程短、家长同意，能否代替上路年龄要求？ |
| 场景 | 放学后的校园林荫道 |
| 结尾 | 两位男生接受提醒，继续推着普通自行车走 |
| 长度 | 约一分钟 |

选题确定后，把它压成一句话：“三个同学放学路上讨论能否骑电动车，最后一起作出更安全的选择。”这句话就是剧本的方向。

涉及知识性内容时，先核对事实。本片参考[《中华人民共和国道路交通安全法实施条例》第七十二条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_92d27a3736be4585af2357930349374c.html)：在道路上驾驶自行车须年满12周岁，驾驶电动自行车须年满16周岁。因此，13岁的林浩在画面里推的是普通自行车。
