# 提示词写到能拍出来

我会按这个顺序写视频提示词：

1. 画风、人物和场景参考。
2. 这一段开始时，人物分别在哪、在做什么。
3. 每个镜头的时长、景别、动作和说话人。
4. 台词、语气、停顿，以及其他人的反应。
5. 环境声和结尾留白。

例如许诺的提醒，可以写成：

> 许诺中近景，镜头缓慢推进。她先看张伟，说话时把目光自然转向林浩，温和认真地说：“爸妈同意，也得守交规呀。咱们都没满十六岁，不能骑电动自行车上路。”两位男生安静听着，林浩的神情慢慢放松。

这里既有台词，也有目光、镜头和情绪变化。把“认真劝导”写成看得见的表演，生成时才有具体的落点。

参考素材按用途命名：`linhao`、`xunuo`、`campus`、`linhao_voice`。导出命令会把本段需要上传的素材和提示词放在一起：

```bash
aivideo prompts examples/traffic-safety/project.json --output workspaces/traffic-prompts
```

打开导出的 G1.md 或 G2.md，按清单上传参考，再使用正文。平台要求引用素材时，把对应的人物、声音和末帧绑定到相应位置。

图像和视频的通用写法分别放在[图像提示词](../prompts/04-images.md)与[视频提示词](../prompts/05-video.md)。
